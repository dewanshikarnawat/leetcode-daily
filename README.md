## 🧠 My Approach

Every solution follows this structure:

1. **Understand** — restate the problem in plain English
2. **Brute Force** — naive approach + why it's slow
3. **Optimal** — key insight that improves it
4. **Code** — clean, commented implementation
5. **Complexity** — time and space analysis

Topics covered so far:

`Array` `Hash Map` `Two Pointers` `Sliding Window` `Binary Search` `Dynamic Programming` `Graph` `BFS/DFS` `Backtracking` `Heap`
